# CTB-UPM

Este repositorio contiene el sistema completo, dividido en dos repositorios:

- Backend ([upm-backend](https://github.com/mafedev/upm-backend))
- Frontend ([upm-front](https://github.com/mafedev/upm-front))
  - Android Front (`android_front_upm`)
  - Windows Front (`windows_front_upm`)

Cada subproyecto es independiente y cuenta con su propia configuración y documentación dentro de su respectivo directorio
